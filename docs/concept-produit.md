# Cookimix Brasil

## Concept produit détaillé pour une PWA de recettes intelligentes, multi-équipements et personnalisées

---

## 1. Résumé exécutif

Cookimix Brasil est une application de cuisine pensée d'abord comme une PWA personnelle, puis comme un produit grand public destiné au marché brésilien.

Le concept reprend ce qui fait la force de Cookomix :

- des recettes très visuelles ;
- une navigation simple sur mobile ;
- une fiche recette claire ;
- des étapes structurées ;
- un mode cuisine guidé ;
- des minuteries intégrées ;
- une expérience proche de celle d'un Thermomix.

Mais l'application élargit fortement le concept.

Au lieu de dépendre d'un seul appareil, elle adapte chaque recette aux équipements réellement disponibles chez l'utilisateur :

- air fryer ;
- four ;
- plaque de cuisson ;
- casserole ;
- poêle ;
- Thermomix ;
- robot multifonction ;
- blender ;
- panela de pressão ;
- panela elétrica ;
- churrasqueira ;
- micro-ondes.

L'application adapte également la recette selon l'objectif de l'utilisateur :

- version originale ;
- version légère ;
- version riche en protéines ;
- version économique ;
- version rapide ;
- version low carb ;
- version végétarienne ;
- version sans lactose ;
- version sans gluten.

Le cœur du produit est donc simple :

> Une même recette peut être adaptée à la cuisine, aux appareils, aux objectifs nutritionnels, au temps disponible et aux ingrédients de chaque utilisateur.

Le MVP doit d'abord être suffisamment bon pour remplacer, dans l'usage quotidien, la combinaison actuelle suivante :

1. chercher une recette sur Cookomix ou ailleurs ;
2. faire des captures d'écran ;
3. copier la recette dans ChatGPT ;
4. demander une adaptation ;
5. recalculer les quantités ;
6. réorganiser les étapes ;
7. cuisiner à partir d'une réponse non structurée.

L'application doit transformer ce processus en une expérience spécialisée, rapide, visuelle et réutilisable.

---

# 2. Vision produit

## 2.1 Vision à long terme

Créer la plateforme de recettes la plus adaptable du Brésil.

L'utilisateur ne cherche plus seulement une recette.

Il cherche une recette qui fonctionne :

- avec les appareils qu'il possède ;
- avec les ingrédients disponibles ;
- avec son objectif nutritionnel ;
- avec le nombre de personnes à servir ;
- avec le temps dont il dispose ;
- avec son niveau en cuisine.

La vision à long terme est celle d'un assistant culinaire universel.

L'application devient capable de répondre à des demandes telles que :

> Je veux un déjeuner léger avec du poulet, moins de 500 calories, au moins 35 grammes de protéines, préparé avec mon air fryer et ma plaque de cuisson.

Ou :

> Je veux faire cette recette Cookomix, mais je n'ai pas de Thermomix. Adapte-la pour mon air fryer et mon four.

Ou encore :

> J'ai du thon, des tomates, de l'avocat et des œufs. Propose-moi une recette rapide pour deux personnes.

---

## 2.2 Vision du MVP

Le MVP ne doit pas chercher à résoudre toute la cuisine.

Il doit résoudre parfaitement un problème personnel concret :

> Pouvoir sélectionner une recette, choisir ses équipements et son objectif nutritionnel, puis la cuisiner étape par étape sur son téléphone.

Le MVP doit donc permettre de :

- consulter un catalogue de recettes ;
- filtrer selon les appareils ;
- choisir une version nutritionnelle ;
- adapter les portions ;
- suivre la recette étape par étape ;
- lancer les minuteries ;
- enregistrer ses recettes favorites ;
- créer et modifier les recettes depuis un back-office.

---

# 3. Positionnement

## 3.1 Positionnement principal

Cookimix Brasil ne doit pas être présenté comme une simple copie de Cookomix.

Le positionnement recommandé est :

> Un assistant culinaire brésilien qui adapte chaque recette aux équipements, aux objectifs et aux habitudes de l'utilisateur.

Autres formulations possibles :

> Qualquer receita. Do seu jeito. Com os aparelhos que você tem.

> Sua receita, seus objetivos, sua cozinha.

> Escolha o prato. A gente adapta o resto.

---

## 3.2 Différence avec Cookomix

| Cookomix classique                      | Cookimix Brasil                                         |
| --------------------------------------- | ------------------------------------------------------- |
| Centré sur le Thermomix                 | Multi-équipements                                       |
| Une recette structurée pour un appareil | Plusieurs parcours de préparation                       |
| Instructions fixes                      | Instructions adaptables                                 |
| Catalogue principalement Thermomix      | Catalogue généraliste brésilien                         |
| Version standard                        | Originale, légère, protéinée, rapide                    |
| Recherche par recette                   | Recherche par envie, objectif, ingrédients ou appareils |
| Communauté de recettes                  | Assistant personnel de cuisine                          |
| Recette identique pour tous             | Recette personnalisée                                   |

---

## 3.3 Porte d'entrée marché

Le Thermomix n'est pas suffisamment répandu au Brésil pour constituer seul la base du produit.

L'air fryer est le meilleur point d'entrée.

Pourquoi :

- équipement très répandu ;
- forte fréquence d'utilisation ;
- recherche constante de nouvelles recettes ;
- association naturelle avec la cuisine rapide ;
- perception de cuisine plus légère ;
- grand potentiel de contenu social ;
- compatibilité avec les habitudes alimentaires brésiliennes.

Le produit peut donc démarrer comme une application très forte sur les recettes air fryer, puis s'étendre à l'ensemble de la cuisine.

# 4. Utilisateurs cibles

## 4.1 Utilisateur initial

Le premier utilisateur est le fondateur lui-même.

Profil :

- cuisine régulièrement ;
- utilise Cookomix et ChatGPT ;
- veut gagner du temps ;
- cherche à manger plus léger ;
- veut augmenter son apport en protéines ;
- possède plusieurs appareils ;
- aime suivre une recette de manière visuelle ;
- ne veut pas recalculer les quantités à chaque fois.

---

## 4.2 Cibles grand public futures

### Utilisateur air fryer

Il veut :

- des recettes simples ;
- des temps fiables ;
- des températures précises ;
- des plats croustillants ;
- moins d'huile ;
- des recettes adaptées à la taille de son appareil.

### Utilisateur en déficit calorique

Il veut :

- connaître les calories ;
- éviter les substitutions absurdes ;
- conserver le goût ;
- manger rassasiant ;
- augmenter les protéines ;
- ajuster les portions.

### Utilisateur pressé

Il veut :

- cuisiner en moins de 30 minutes ;
- utiliser peu de vaisselle ;
- utiliser ce qu'il a ;
- suivre des étapes optimisées.

### Utilisateur multi-équipements

Il veut savoir quelle combinaison utiliser :

- air fryer + plaque ;
- Thermomix + air fryer ;
- four + plaque ;
- blender + poêle ;
- panela de pressão + four.

### Utilisateur débutant

Il veut :

- une seule instruction à la fois ;
- des visuels ;
- des températures explicites ;
- des alertes ;
- des conseils simples ;
- éviter le jargon culinaire.

# 6. Principes produit

## 6.1 Simple avant d'être intelligent

L'application ne doit jamais donner l'impression d'être un chatbot compliqué.

L'IA doit être invisible.

L'utilisateur choisit simplement :

- une recette ;
- une version ;
- des appareils ;
- des portions.

L'application fait le reste.

---

## 6.2 Visuel avant d'être textuel

L'application doit être utilisable en cuisine.

Les écrans doivent privilégier :

- grandes photos ;
- gros boutons ;
- grandes typographies ;
- instructions courtes ;
- icônes claires ;
- très peu de texte simultané ;
- navigation tactile facile.

---

## 6.3 Fiable avant d'être exhaustif

Une petite base de recettes très bien validées vaut mieux qu'un énorme catalogue généré automatiquement.

Le MVP doit privilégier :

- 50 à 100 recettes fiables ;
- temps vérifiés ;
- quantités cohérentes ;
- substitutions testées ;
- instructions propres ;
- photos homogènes.

---

## 6.4 Adaptation structurée

L'application ne doit pas réécrire librement une recette entière à chaque utilisation.

Elle doit s'appuyer sur :

- une recette de référence ;
- des variantes d'ingrédients ;
- des parcours de préparation ;
- des règles de transformation ;
- des données nutritionnelles ;
- des étapes structurées.

# 11. Mode cuisine guidé

## 11.1 Objectif

Créer une expérience proche de l'écran d'un Thermomix.

L'utilisateur doit pouvoir suivre la recette sans lire une longue page.

Une étape à la fois.

---

## 11.2 Structure d'un écran

- numéro de l'étape ;
- progression ;
- instruction principale ;
- ingrédient concerné ;
- appareil ;
- durée ;
- température ;
- vitesse éventuelle ;
- bouton minuteur ;
- bouton précédent ;
- bouton suivant.

---

## 11.3 Exemples

### Air fryer

```text
Étape 6 sur 11

Placez le poulet dans l'air fryer

190 °C

12 minutes

[Lancer le minuteur]
```

### Thermomix

```text
Ajoutez les tomates dans le bol

8 minutes
100 °C
Vitesse 2
Sens inverse
```

### Plaque

```text
Faites chauffer à feu moyen

6 minutes

Remuez régulièrement
```

---

## 11.4 Interactions utiles

- swipe gauche ou droite ;
- bouton suivant très large ;
- écran toujours allumé ;
- vibration en fin de minuterie ;
- notification locale ;
- ajout d'une minute ;
- pause ;
- retour à l'étape précédente ;
- coche de validation ;
- affichage rapide des ingrédients concernés.

---

## 11.5 Mode parallèle

# 12. Adaptation aux appareils

## 12.1 Philosophie

Une recette ne doit pas être liée à un seul appareil.

Elle doit contenir plusieurs méthodes possibles.

---

## 12.2 Exemples de parcours

### Frango à parmegiana

#### Air fryer + four

- poulet dans l'air fryer ;
- sauce sur la plaque ;
- gratinage au four.

#### Plaque + four

- poulet à la poêle ;
- sauce dans une casserole ;
- gratinage au four.

#### Thermomix + air fryer

- sauce au Thermomix ;
- poulet à l'air fryer ;
- assemblage final.

#### Air fryer uniquement

- cuisson du poulet ;
- ajout de sauce ;
- gratinage final dans le panier.

---

## 12.3 Données nécessaires par appareil

Chaque variante doit préciser :

- appareil ;
- température ;
- durée ;
- puissance ;
- accessoire ;
- capacité ;
- quantité maximale ;
- préchauffage ;
- niveau de chaleur ;
- vitesse ;
- sens de rotation ;
- couvercle ou non.

# 13. Adaptation nutritionnelle

## 13.1 Modes du MVP

### Original

Version de référence.

### Leve

Objectif :

- réduire les calories ;
- limiter les matières grasses ;
- conserver le goût ;
- maintenir la satiété.

### Proteica

Objectif :

- augmenter la protéine ;
- contrôler les calories ;
- éviter les portions disproportionnées ;
- maintenir une bonne texture.

---

## 13.2 Règles de substitution

Exemples :

- crème entière vers yaourt nature ;
- mayonnaise vers yaourt et moutarde ;
- fromage abondant vers quantité réduite et fromage plus intense ;
- viande grasse vers viande maigre ;
- friture vers air fryer ;
- sucre vers réduction ou substitut ;
- pâte abondante vers légumes ou protéines ;
- requeijão classique vers requeijão light ;
- crème vers cottage mixé ;
- sauce lourde vers ricotta fouettée.

---

## 13.3 Produits adaptés au Brésil

# 15. Intelligence artificielle

## 15.1 Rôle de l'IA

L'IA doit assister le produit, pas le remplacer.

Elle peut :

- comprendre une demande en langage naturel ;
- extraire une recette ;
- proposer des substitutions ;
- recalculer les portions ;
- reformuler des étapes ;
- adapter une recette ;
- expliquer un geste ;
- remplacer un ingrédient ;
- répondre pendant la préparation.

---

## 15.2 Exemples

Utilisateur :

> Je n'ai plus de crème.

Réponse :

> Utilisez 120 g de cottage mixé avec 30 ml de lait. La recette contiendra environ 65 calories de moins par portion.

Utilisateur :

> Je n'ai qu'un air fryer.

Réponse :

> La recette peut être faite entièrement à l'air fryer. La sauce sera simplifiée et le gratinage se fera dans les trois dernières minutes.

---

## 15.3 Garde-fous

L'IA ne doit pas :

- inventer librement les temps critiques ;
- proposer des températures dangereuses ;
- remplacer des ingrédients sans logique ;
- modifier les allergènes silencieusement ;
- supprimer des étapes indispensables ;
- improviser des recettes sensibles.

Les adaptations doivent être :

- validées ;
- traçables ;
- réversibles ;
- structurées.

# 27. Risques principaux

## Risque 1. Trop vouloir faire dès le départ

Solution :

- limiter le MVP ;
- sélectionner peu d'appareils ;
- garder seulement trois modes ;
- utiliser peu de recettes.

## Risque 2. IA peu fiable

Solution :

- recettes structurées ;
- règles validées ;
- contrôle humain ;
- adaptations limitées.

## Risque 3. Données nutritionnelles incohérentes

Solution :

- base nutritionnelle fiable ;
- quantités normalisées ;
- calcul centralisé ;
- marge d'erreur explicite.

## Risque 4. UX trop complexe

Solution :

- une action principale par écran ;
- choix par défaut ;
- recommandations automatiques ;
- profils enregistrés.

## Risque 5. Clone trop proche

Solution :

- conserver la logique d'usage ;
- créer une identité propre ;
- développer des fonctionnalités différenciantes ;
- produire son propre contenu.

# 28. Conclusion

Cookimix Brasil peut commencer comme une PWA personnelle très simple et très utile.

Le produit ne doit pas chercher immédiatement à devenir une grande plateforme.

Il doit d'abord réussir une mission claire :

> Permettre de choisir une recette, de l'adapter aux appareils disponibles et à l'objectif nutritionnel, puis de la cuisiner pas à pas depuis un téléphone.

La force du projet repose sur quatre éléments :

1. une expérience visuelle inspirée de Cookomix ;
2. un mode cuisine proche de l'écran d'un Thermomix ;
3. une adaptation multi-équipements ;
4. une personnalisation nutritionnelle.

Le produit pourra ensuite évoluer vers une plateforme grand public.

La meilleure première validation sera simple :

> Utiliser la PWA pendant plusieurs semaines pour cuisiner au quotidien, sans avoir besoin de retraiter chaque recette manuellement avec ChatGPT.

---

# 29. Formulation courte du concept

> Cookimix Brasil est une PWA de recettes intelligentes qui adapte chaque plat aux équipements disponibles, aux objectifs nutritionnels, aux portions et aux ingrédients de l'utilisateur. L'expérience est très visuelle et permet de cuisiner étape par étape, avec des instructions et des minuteries adaptées à l'air fryer, au four, à la plaque, au Thermomix et aux autres appareils de cuisine.
